# Объединенное приложение лабораторных работ, часть 2

Объединяет в одном Spring Boot приложении домашнюю страницу, доменную модель варианта 3, репозитории JDBC, PostgreSQL, веб-представление, вход по форме и CRUD-операции для фильмов и персонажей.

## Запуск

Нужны JDK 17+ и Maven. PostgreSQL должен быть доступен на `127.0.0.1:5432`; при первом запуске приложение создаст базу `films_lab` заранее (саму базу нужно создать отдельно), таблицы и демонстрационные записи.

Из PowerShell в папке проекта задайте пароль, который установлен для пользователя PostgreSQL `postgres`, и выполните:

```powershell
$env:FILMS_DB_PASSWORD='ваш-пароль'
mvn spring-boot:run
```

Либо соберите исполняемый JAR:

```powershell
mvn clean package
java -jar target/films-full-project.jar
```

Переопределить подключение можно переменными `FILMS_DB_URL`, `FILMS_DB_USER`, `FILMS_DB_PASSWORD`; порт приложения — переменной `PORT` (по умолчанию 8080).

Откройте `http://localhost:8080`. Учетные записи демонстрационные: `student` / `film123` или `admin` / `admin123`. Для реального использования пароли и механизм хранения пользователей следует заменить.
